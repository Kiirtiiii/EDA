## Spotify_user_churn_analysis
Exploratory Data Analysis (EDA) and customer churn analysis on Spotify user data using Python, Pandas, NumPy, Matplotlib and Seaborn.

##Overview
This projects analyzes Spotify user data using Python to understand user behavior and identify factors related to customer churn.

## Objectives
Perform Exploratory Data Analysis (EDA)
Analyze customer churn patterns
Generate business insights through data visualization
## Tools Used
Python
Pandas
NumPy
Matplotlib
Seaborn
VS Code

## Phase 1: Spotify Analysis
The first report focuses on exploratory data analysis (EDA) to understand the dataset and user behavior. This phase helped understand the data and discover areas that required deeper investigation. 
### -Related files: spotify.analysis.py kirti_spotify_analysis.pdf The findings from this exploratory analysis highlighted customer churn as an area worth investigating further.

## Phase 2: Spotify Churn Analysis
Based on the insights gained during the exploratory analysis, the second phase focuses specifically on customer churn. Additional visualizations and analysis were performed to identify factors associated with churn and provide business-oriented insights.
### -Related files: spotify_churn_analysis.py spotify_churn_analysis.pdf This second phase demonstrates how initial exploration can lead to more focused questions and deeper business analysis.

## Why are there two reports?
The first report was my initial attempt at analyzing the dataset through exploratory data analysis (EDA). While reviewing it, I realized that many of the visualizations described the data but didn't answer a specific business question.

Instead of considering the project complete, I revisited the dataset and focused on customer churn. This led to a second report with more targeted analysis, additional visualizations, and clearer business insights.

Both reports are included to show how the analysis evolved and how refining the approach resulted in a more meaningful outcome.
